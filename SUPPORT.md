# Getting help

| You need | Go to |
|---|---|
| To ask a question about an article | Comment on the article at [codemwangi.substack.com](https://codemwangi.substack.com), or start a Q&A thread in [Discussions](https://github.com/orgs/Engineering-Notes/discussions) |
| To report code that fails or gives different results | A **Bug report** issue in the series repository |
| To report an error in an article | An **Article correction** issue in the series repository |
| To propose a topic or an improvement | **Ideas** in [Discussions](https://github.com/orgs/Engineering-Notes/discussions) |
| To report a security issue | The [security policy](SECURITY.md) |

Engineering Notes is maintained on a best-effort basis. Clear reports with steps to reproduce get answered first.
