# Engineering-Notes/.github

Organisation-wide files for [Engineering Notes](https://github.com/Engineering-Notes).

| Path | Purpose |
|---|---|
| `profile/README.md` | The public organisation profile |
| `CONTRIBUTING.md`, `CODE_OF_CONDUCT.md`, `SECURITY.md`, `SUPPORT.md`, `GOVERNANCE.md` | Default community health files for every repository that does not define its own |
| `ISSUE_TEMPLATE/`, `PULL_REQUEST_TEMPLATE.md` | Default issue forms and pull request template |
| `DISCUSSION_TEMPLATE/` | Forms for organisation Discussions categories |
| `workflow-templates/` | The article CI workflow, offered when creating a workflow in any organisation repository |
| `labels.json` | The standard label set applied to every repository |
